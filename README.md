# 公交营运预算调整工具

第一版围绕《2027年预算基础表》工作，暂不接入《2027年预算编制表》。使用中文网页，输入由人决定，计算由保留的工作簿原公式完成。

**Mac 用户从这里开始：[Mac第一次使用](Mac开始使用.md)。** 打开“启动预算工具.command”即可检查环境并启动浏览器。源码不包含用户预算 Excel、截图或云端方案。

## 在当前云环境使用

在 `/workspace/1` 运行：

```bash
bash install.sh
bash start.sh
```

服务默认使用8000端口，`PORT=8001 bash start.sh` 可更换端口。用环境提供的端口访问方式打开网页。停止服务使用 Ctrl+C。每个云任务已经隔离，使用现有仓库，无需创建 Git worktree。

当前环境提供 Python 3.12、LibreOffice Calc 和所需 Python 包。安装脚本在仓库内建立虚拟环境，固定依赖版本，不修改系统环境。其他机器需要先提供 Python 3.12+ 和 `soffice`；缺少真实电子表格引擎时，程序会拒绝试算。

## 页面操作

1. 打开已提供的基础表，或上传相同结构的 `.xlsx` 文件。首次导入会用真实引擎进行空操作重算，对照全部原公式结果；不会覆盖原文件。
2. 选择月份、业务部和线路；勾选要调整的记录。默认不勾选任何线路。锁定按线路生效，覆盖该线路所有月份。
3. 点击“投放减少1台”。唯一可改的业务输入是月表 J 列，即 A 计划营运1的投放车辆数。负数、非法整数、锁定记录会使整批操作失败，不会部分应用。
4. 核对 A 计划日趟次、月趟次变化和异常。局部恢复回到**当前草稿父版本**；撤销回到上一步，操作仍进入审计记录。
5. 填写原因保存 V1、V2……可以从任意已保存版本建立新方案，版本保存后不能覆盖。
6. 导出“月趟次试算表”或完整原公式工作簿。草稿须先保存才能导出。

## 计算与数据边界

- 不重写营运业务公式，不用固定值替换原公式。只向原 XML 的 J 列写入获准的投放数。
- 在隔离副本中使用 LibreOffice 重算，核验后只合并计算缓存回原 XML。原公式、共享公式、原表格式及其他包内容保留；源文件不经过 openpyxl 整本另存。
- 导入保留 V0 原始字节和 SHA-256。每次操作成功重算后才更新草稿；失败保留先前状态。
- 月趟次目前是原“汇总”表31列逐日结果的合计。原表2月等月份有超月日期，本版保留并提示，**不裁剪日期、不自行重排计划**。
- 原表已有负机动车、单车趟次缺失、跨月引用等，均保留并提示。区分原有和新增异常；新的公式错误不应用到草稿。
- 公里数换算、最低投放/最低趟次、日期类型之间的大小关系及合法小数步长尚未确认，界面显示待确认。当前可设置的目标仅为“希望减少的月趟次”。
- “月趟次试算”是新增的对照报告页，引用原汇总公式，注明版本、原因、来源指纹与31列口径；尚不是已确认的正式报送模板。

## 原始文件与版本保存

数据保存在 `data/datasets/<数据集ID>/`，已由 Git 忽略：

- `original.xlsx`：只读原文件。
- `baseline-calculated.xlsx`：空操作重算对照，独立于原文件。
- `versions/<版本ID>.xlsx`、`.json`：每个不可覆盖的方案及修改范围、前后值、原因、父版本、时间、结果。
- `draft.json`、`draft-files/`：未保存草稿及计算产物。
- `discarded-drafts/`：明确放弃的草稿记录。
- `exports/`：已保存版本的导出文件。

导入另一个文件会切换当前数据集，先前数据集目录保留。数据保存在当前环境磁盘，需通过导出保留重要结果；本版按单人工作台实现，不包含多人账号和权限管理。

可用环境变量：`BUS_BUDGET_DATA_DIR` 指定数据目录，`BUS_BUDGET_DEMO_PATH` 指定页面“已提供基础表”的路径，`BUS_BUDGET_SOFFICE` 指定 Calc 可执行文件，`PORT` 指定云端服务端口。不需要密钥。未配置示例文件时，网页仅提供上传自己的基础表。

## 验证

```bash
python3 -m unittest discover -s tests -v
```

测试使用临时目录与真实基础表，真实调用电子表格引擎，不替换业务计算。核心样例为1月136路：J7从15减到14，汇总F4从60变56，18个A计划日各减少4趟，月趟次1536变1464。还检查原公式逐字保留、原文件指纹不变、锁定与负数拦截、撤销/恢复、版本保存和Excel导出。

源文件缺失时，依赖真实上传文件的验收会明确跳过；不能把跳过视为通过。API验收文件路径使用 `TEST_WORKBOOK`，引擎验收使用 `BUDGET_TEST_WORKBOOK`，默认均读取本次上传的基础表。新机器运行测试前可安装 `requirements-dev.txt`。

自动验收使用 LibreOffice 兼容引擎；Microsoft Excel 桌面版逐格手工对照未在云环境运行。导出的验收方案可以用于桌面 Excel 复核。
